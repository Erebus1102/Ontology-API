# TKOS Ontology V2.4 人读分类层级修订

## 目标

V2.3 的 `BusinessEntity` 是统一治理根，很多概念直接挂在其下，适合机器侧的通用属性与约束，却使 Protégé 的初始类树过于平铺。V2.4 在不改变对象关系、状态机、SHACL 约束与 SWRL 规则的前提下，补充稳定的抽象分类层。

## 新的顶层结构

```text
BusinessEntity
├── StrategicEntity
│   ├── CompanyReality
│   ├── CompanyConstitution
│   ├── StrategicSignal
│   ├── StrategicIssue / StrategicResearch
│   ├── StrategicChoice
│   └── StrategicDecision
├── OperatingEntity
│   ├── Outcome → CompanyOutcome / DomainOutcome / MissionOutcome
│   ├── Domain / DomainPurpose / MissionPortfolio
│   ├── Mission → MissionReadyForAcceptance
│   ├── MissionScope / SuccessCriterion / KeyPath / Milestone / Dependency
│   ├── OperatingAction / WorkPattern / RuleCondition
│   └── OutcomeContribution / OperatingDecision
├── DecisionProvenanceEntity
│   ├── DecisionRecord
│   ├── AttributedAssertion → DecisionLearning / Judgement / IntentAssessment
│   ├── DecisionProfileView
│   ├── EvidenceSupport / EvidenceChallenge
│   └── Decision
├── GovernanceEntity
│   ├── Actor → Person / Agent
│   ├── Role → DirectlyResponsibleRole / DecisionMakerRole
│   ├── RoleAssignment / OrganizationalUnit
│   ├── Policy → CompanyConstitution / AuthorityBoundary
│   ├── Confirmation → ConfirmationEvent
│   ├── RevisionEvent / KnowledgeGraphPartition
│   └── OntologyModule
└── ContextAsset
    ├── Evidence / SourceRecord / Artifact / Lesson / ContextGap
    ├── Risk / ProgressSnapshot / MissionRationale / MissionReview
    ├── Decision / AttributedAssertion / DecisionProfileView
    ├── StrategicSignal / StrategicIssue / StrategicResearch
    └── ContextPack
```

## 多重继承的处理

`ContextAsset` 表达可引用、确认、复用和治理的信息资产；四个抽象分类表达业务语义位置。战略信号既属于 `ContextAsset`，也属于 `StrategicEntity`；决策、归属断言和决策画像既属于 `ContextAsset`，也属于 `DecisionProvenanceEntity`。Protégé 会在两个父类下展示这些交叉概念，帮助读者从资产视角或业务视角进入同一对象。

## Protégé 查看副本

运行 `python3 scripts/export_protege_view.py` 会生成 `ontology/views/tkos-ontology-protege-view.ttl`。该文件移除了外部 `owl:imports`，因此 FOAF、PROV、ORG、SKOS 和 OWL-Time 的外部类树不会干扰 TKOS 结构浏览；`time:Interval` 仍可能以被引用的类型出现，用于表达 RoleAssignment 的有效区间。

## 回归结果

- 本体 JSON-LD 与 Protégé Turtle 查看副本均可解析。
- `BusinessEntity` 的直接分支为 `ContextAsset`、`DecisionProvenanceEntity`、`GovernanceEntity`、`OperatingEntity`、`StrategicEntity`。
- V2.3 SHACL 正向与五个负向用例全部保持预期。
- V2.3 四个 SWRL 验收推导场景全部保持预期。
- Context Pack 运行时筛选验证保持通过。

# ADR-0001 组织作用域与跨组织查询

状态：已确认

日期：2026-08-11

## 决策

集团、子公司和项目使用组织作用域。组织作用域用于事实归属、确认责任、访问过滤和来源解释。

集团级议题可以同时查询集团共享图、多个子公司图、项目图和获准的跨组织关系。查询范围由议题、调用主体、用途和策略共同决定。

## 结果

- API 1 使用 `organization_scope` 数组，并支持 `include_descendants` 和 `include_projects`。
- 数据图同时具有组织范围、治理分区和 Release 版本。
- 跨组织关系使用可记录来源和确认状态的关系对象。
- 子公司共享核心 TBox，可加载各自扩展模块与 Profile。
- 组织边界不能被实现为单选租户切换。
